    Операционные системы

    Операционные системы

    ⚙️

    Системы Apple от первой System для Macintosh до современной macOS, iOS, iPadOS, watchOS и visionOS.

    macOS (с 1984 — System, с 2001 — Mac OS X)

    У Apple несколько операционных систем: macOS для Mac, iOS для iPhone, iPadOS для iPad, watchOS для часов и visionOS для Vision Pro. Все современные системы Apple выросли из Mac OS X, основой которой стала система NeXT. Ниже рассказано о главной из них — macOS.

    macOS (сокращение от Macintosh Operating System) — операционная система Apple для компьютеров Macintosh. Она тесно связана с iOS — мобильной системой Apple для iPhone и iPod touch.

    Сначала она называлась просто System. Она вышла вместе с Macintosh 128K в январе 1984 года и стала первой коммерчески успешной системой с полностью графическим интерфейсом. В марте 1995 года, с обновлением, System 7.5 стала называться Mac OS 7.5.1. Позже название системы менялось ещё несколько раз.

    В декабре 1996 года Apple Computer купила NeXT — компанию сооснователя Apple Стива Джобса — ради её программных технологий. Прежние версии системы задним числом стали называть «классической» Mac OS, а на смену им пришла Mac OS X. Она была построена на NeXTSTEP — более надёжной системе, происходящей от Unix. Каждую версию, начиная с Mac OS X 10.0 Cheetah («Гепард»), называли в честь дикой кошки. С OS X 10.9 Mavericks из названия официально убрали слово «Mac», а версии стали называть в честь природных мест Калифорнии. С macOS 10.12 Sierra система вернулась к старому имени, но в стиле мобильных систем Apple, выросших из неё: iOS, iPadOS, tvOS и watchOS.

    Происхождение

    Операционную систему Macintosh разрабатывали Билл Аткинсон, Энди Херцфельд и Джеф Раскин с 1979 года по январь 1984 года. Откуда взялись её основные идеи, рассказывают по-разному. Хорошо известна связь разработки Mac с проектом Alto в Xerox PARC. Сам Alto, в свою очередь, вдохновлялся системой Sketchpad Айвена Сазерленда и oN-Line System Дага Энгельбарта — первопроходцами графического интерфейса.

    Совместимость

    Macintosh работает на своей особой системе, которую в основном разрабатывали независимо от других распространённых систем того времени. Ей нужны оборудование и программы, созданные специально для неё. Для продуктов Apple это удобно, но пользователей PC это могло раздражать: Mac OS не была рассчитана на совместимость с оборудованием и программами для PC. У Mac OS свой набор API (программных интерфейсов), и программы для неё обращаются к уже готовым API. Поэтому на PC такие программы обычно не работали без эмуляции. Но после перехода Apple на процессоры Intel начинка новых Mac стала больше похожа на PC, и пользователи нашли способы запускать Windows прямо на Mac, а Mac OS — на PC.

    Версии

    Сначала система Macintosh называлась System, например «System 6». В первые годы Apple нарочно не подчёркивала, что у Macintosh вообще есть операционная система. Так компьютер казался дружелюбнее и отличался от систем вроде CP/M и MS-DOS, которые выглядели загадочными и сложными. Apple хотела, чтобы Macintosh воспринимали как машину, которая «просто работает», как только её включишь.

    С самого начала в системе Macintosh был Toolbox — набор стандартных функций, которые программы вызывали вместо прямого обращения к оборудованию. Благодаря этому программы, написанные для одного поколения Mac, работали и на следующих: например, от Mac Plus до Mac II, PowerBook и Power Macintosh. Слова «система» и «тулбокс» были удобным способом говорить о службах системы и API Macintosh без технических терминов. До появления компьютеров на PowerPC G3 (так называемых машин «нового мира») большая часть системы хранилась в микросхеме ПЗУ на материнской плате, а остальные части лежали на диске и дополняли или исправляли код из ПЗУ. Так система занимала меньше места на дискетах — у первых Mac не было жёсткого диска. Одна модель, Macintosh Classic 1991 года, даже могла загружаться только из ПЗУ: в ней был раздел восстановления.

    Mac OS 7.5.1 стала первой версией с логотипом Mac OS — голубым улыбающимся лицом. Mac OS 7.6, вышедшая в 1996 году, первой официально получила название Mac OS. Имя сменили из-за появления «клонов» Mac — похожих компьютеров других фирм, например Power Computing и Motorola. Apple хотела ясно показать, что операционная система — её интеллектуальная собственность.

    Mac OS делится на два семейства систем:

    • Классическая Mac OS — система, которая вышла с первым Mac в 1984 году, и её потомки вплоть до Mac OS 9. Есть версии для процессоров Motorola 68000 (M68k) — от System 1 до Mac OS 8.1 — и для процессоров Motorola PowerPC с архитектурой RISC — от System 7.1 до Mac OS 9. Программы, которые работали на обеих, называли «толстыми» (fat): в них был код для обеих архитектур.
    • Более новая Mac OS X («X» читается как «десять», как римская цифра). В ней есть элементы BSD Unix, OpenStep и Mac OS 9. Её низкоуровневая основа на базе Unix, Darwin, открыта. Есть версии для PowerPC — от Mac OS X Server 1.0 до Mac OS X 10.5 — и для Intel x86 — от Mac OS X 10.4 до наших дней. Программы для обеих архитектур называли «универсальными» (Universal).

    Классическая Mac OS

    У «классической» Mac OS совсем нет командной строки — это полностью графическая система. Её хвалили за простоту, но критиковали за кооперативную многозадачность, почти полное отсутствие управления памятью и конфликты расширений. «Расширения» (сначала их называли INIT) — модули, которые дополняют систему: добавляют, например, работу с сетью или поддержку какого-то устройства. Некоторые расширения плохо работали вместе или работали только при загрузке в определённом порядке. Искать проблему приходилось долго, методом проб и ошибок.

    В Mac OS появилась файловая система Macintosh File System, а за ней — более надёжная Hierarchical File System. В DOS или Unix файл — это просто последовательность байтов на диске, и программа сама должна знать, где код, а где картинки или другие данные. У файлов Mac было две «ветви». Кроме ветви данных с байтами была ветвь ресурсов со структурированными данными: описаниями меню, картинками, звуками или кусками кода. Файл программы мог состоять только из ресурсов. Текстовый файл мог хранить текст в ветви данных, а оформление — в ресурсах, и программа, которая не понимает оформления, всё равно могла прочитать текст. Но с другими системами, которые не знали о таком устройстве файлов, работать было трудно: например, при копировании файла с Mac в DOS или Unix ветвь ресурсов терялась.

    К середине 1990-х стало ясно, что технологии 1980-х отживают своё: появлялись более стабильные многозадачные системы. После нескольких неудачных попыток создать систему «нового поколения» своими силами Apple в 1996 году купила NeXT, чтобы на основе её системы быстрее построить современную.

    Mac OS X

    Mac OS X принесла на Mac управление памятью в стиле Unix и вытесняющую многозадачность. Благодаря новому управлению памятью одновременно могло работать больше программ, а одна программа почти не могла «уронить» другую. Это также первая Mac OS с командной строкой вне инструментов для разработчиков, хотя пользователь её не видит, пока не откроет программу «Терминал».

    Новые возможности требовали больше ресурсов, поэтому Mac OS X официально поддерживает только процессоры PowerPC G3 и новее, и даже на старых G3 она работает медленно. Любопытно, что каждое обновление — от первой публичной беты до Mac OS X 10.6 — работало заметно быстрее предыдущей версии, хотя у большинства систем бывает наоборот.

    В Mac OS X от публичной беты до версии 10.4 была среда Classic для запуска старых программ Mac (программисты называли её «синей коробкой»). Она запускала полную копию Mac OS 9 как процесс Mac OS X. Большинство хорошо написанных «классических» программ в ней работало, но совместимость гарантировалась, только если программа не обращалась к оборудованию напрямую, а работала только через систему.

    Многие поклонники старой Mac OS приняли OS X, но некоторые критиковали её как более сложную и менее дружелюбную. С Mac OS X 10.4 для Intel до Mac OS X 10.6 в системе был второй слой совместимости — Rosetta, который запускал программы для PowerPC в OS X на x86.

    Технологии Mac OS

    • QuickDraw — графическая модель, которая первой принесла массовому пользователю принцип WYSIWYG («что видишь, то и получишь»).
    • Finder — интерфейс для просмотра файлов и запуска программ.
    • MultiFinder — первая версия, которая позволяла запускать несколько программ одновременно.
    • Chooser — инструмент для доступа к сетевым ресурсам (например, для включения AppleTalk).
    • ColorSync — технология для правильной передачи цветов.
    • Управление памятью Mac OS — как Mac работал с оперативной и виртуальной памятью до перехода на Unix.
    • Эмуляция Motorola 68000 на PowerPC — как Mac перешёл с архитектуры CISC на RISC.
    • Настольные аксессуары (Desk Accessories) — маленькие вспомогательные программы, которые работали рядом с любой другой программой ещё до MultiFinder и System 7.
    • PlainTalk — технология синтеза и распознавания речи.
    • Mac-Roman — набор символов.
